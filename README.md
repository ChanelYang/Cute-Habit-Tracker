# WarmHabits

A native SwiftUI habit tracker based on the supplied Figma Make prototype. Habits and completion history persist locally using a small Codable store.

Open `WarmHabits.xcodeproj` in Xcode, choose an iPhone simulator, and press Run. The app targets iOS 17 or later and stores data locally with SwiftData.

The first launch includes four sample habits. Delete them from their detail screens to explore the empty state.
